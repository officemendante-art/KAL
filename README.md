## 💡 What does KAL include?

- 🎨 **Beautiful Design & 60+ Color Themes**: Personalize your calculator with dynamic Material You colors that harmonize with your device wallpaper, or select from over 60 vibrant, handcrafted palettes with light and dark themes.
- 🔬 **Scientific & Core Math Mode**: Access advanced mathematical functions including trigonometric calculations, logarithms, powers, roots, factorials, and balanced expression parsing with DEG/RAD precision.
- 💵 **Real-Time Denomination Cash Counter**: Dedicated financial workspace for instant multi-note cash tallies, automatic subtotals, and total currency computation.
- 🔤 **Interactive Number-to-Words Engine**: Live verbalization of calculated amounts in international and localized numerical formats with instant single-tap clipboard copy.
- 🕒 **Persistent Smart History**: Easily track, search, and review previous calculations with timestamped logs, ensuring you never lose important work.
- 📏 **Multi-Category Unit Converter**: Convert units effortlessly across length, weight/mass, speed, temperature, volume, and digital storage.
- 📱 **Adaptive Multi-Form Factor Layout**: Built for fluid responsiveness across phones, landscape mode, and large 7-inch & 10-inch tablets.
- 🔒 **Privacy-First & Completely Offline**: Zero network tracking, zero analytics, zero data collection. All calculations and history stay strictly on-device.

## 🛠️ Building from Source

### Prerequisites
- [Android Studio Ladybug](https://developer.android.com/studio) (2024.2+) or newer
- JDK 17 or JDK 21
- Android SDK 35

### Build Commands
```bash
# 1. Clone the repository
git clone https://github.com/officemendante-art/KAL.git

# 2. Navigate to project root
cd KAL

# 3. Build debug APK
./gradlew assembleDebug
```
The compiled APK will be generated at:
`app/build/outputs/apk/debug/app-debug.apk`
